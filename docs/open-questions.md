# Открытые вопросы

Здесь собраны вопросы, которые ещё не решены. Когда вопрос решён, ответ переносится в [requirements.md](requirements.md), а вопрос удаляется отсюда.

## Ждут ответа

### Замена игрока

1. Результаты соперников в играх против заменённого игрока тоже аннулируются (их победы и шары пропадают), и они заново играют с новым игроком?
2. Заменённый игрок полностью исчезает из таблицы (не зачёркнутой строкой, как выбывший)? В журнале действий замена остаётся.
3. Замена разрешена только на групповом этапе? В плей-офф уже есть «Выбывание» (соперник проходит) и ручное изменение участников сетки.
4. Можно заменить игрока, который раньше выбыл? Тогда его технические поражения тоже аннулируются.
5. Новый игрок — всегда новое имя (вводится при замене)? Выбрать игрока из другой группы нельзя.

### Табло

6. Заглушка: что именно выглядит неправильно на телевизоре? В проверке на разных разрешениях логотип стоит точно по центру.

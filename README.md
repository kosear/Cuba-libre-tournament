# Cuba Libre tournament

Billiards tournament for the Cuba Libre bar: TV screen at `/`, admin panel at `/admin`.

- Prod: https://cubalibre.su (branch `main`)
- Dev: https://dev.cubalibre.su (branch `dev`)

Push to a branch and the server picks it up within 15 seconds. Details, project map and rules: [CLAUDE.md](CLAUDE.md).
Requirements and mockups: [docs/](docs/).

## Local run
```
npm install
cp .env.example .env
npm run dev
```
